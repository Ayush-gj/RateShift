# RateShift 💸
**A Sleek, Minimalist Currency Converter & Financial News Utility**

RateShift is a cross-platform mobile application designed to provide real-time currency conversion with a focus on speed, precision, and a modern "Neon-Finance" aesthetic. Built using **Flutter** and **Dart**, the app prioritizes a clean user experience by maintaining professional-grade features without unnecessary friction.

## 🚀 Key Features
*   **Real-time Conversion**: Instant currency exchange calculations using live market data.
*   **Curated Financial News**: A dedicated news feed filtered to show only relevant market and currency trends.
*   **Professional UI**: A high-contrast, dark-themed interface featuring neon green accents and a custom-designed geometric logo.
*   **Persistent Preferences**: Saves your default base and target currencies, as well as decimal precision settings, using local storage.
*   **Offline Support**: View the most recently cached exchange rates even when you don't have an internet connection.
*   **Theme Customization**: Support for both Light and Dark modes to suit user preference.

## 🛠️ Tech Stack
*   **Framework**: [Flutter](https://flutter.dev/) (Cross-platform).
*   **Language**: [Dart](https://dart.dev/).
*   **State Management**: [Provider](https://pub.dev/packages/provider) for reactive UI updates.
*   **Data Persistence**: [Shared Preferences](https://pub.dev/packages/shared_preferences) for storing user settings.
*   **Networking**: [HTTP](https://pub.dev/packages/http) for API integration.
